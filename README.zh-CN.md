# LJ2600D Print

[English](README.md) | **简体中文**

LJ2600D Print 是一款面向 iOS 16 的实验性打印 App，可将 PDF 和图片通过局域网中的 LPD 服务发送到联想 LJ2600D。它不依赖 AirPrint 发现，用户可以手动填写打印服务器地址和 LPR 队列。

不能安装 App 的设备可使用仓库内的[网页版](WebPrint/README.zh-CN.md)。网页版无需安装，兼容目标为 iOS 16.5.1 至 iOS 27 Safari，以及现代 Android 和桌面浏览器；目前真机打印验证仍以 iOS 16.5.1 为准，iOS 26/27 属于兼容目标。

项目目前主要为 TrollStore 安装设计。核心打印功能使用正常的文档处理和局域网通信能力，并不依赖越狱权限；如有合适的苹果证书和描述文件，也可以重新签名安装。

仓库内的[光猫检测与安装工具](GatewaySetup/README.zh-CN.md)可以只读检查 USB 打印设备、LPD 组件、持久分区和自启动机制，并为已识别的烽火固件安装可撤销的打印服务。遇到未知设备时只生成报告，不会猜测修改厂商启动配置。

## 已实现功能

- 通过系统文件选择器或其他 App 的分享菜单导入 PDF 和图片；
- 打印预览、页码范围、份数、纵向/横向、缩放和单双面打印；
- 300、600 和 1200 dpi 画质选项；
- 针对文字、图形和图片的黑白打印处理；
- 图片旋转、裁剪、边距、明暗和对比度调整；
- 1 合 1、2 合 1、4 合 1 排版，以及可选的页面边框；
- 基于 Brother/Lenovo HBP 栅格格式的 LJ2600D 编码器；
- 通过 RFC 1179 LPR 协议发送打印任务；
- 打印前检查服务状态，并为受支持的烽火光猫提供恢复流程；
- 保存最近成功打印的任务，可快速重打或重新打开并调整设置；
- 提供脱敏诊断记录、只读端口自检和文本报告导出；
- 可在 GitHub Actions 中自动构建 TrollStore IPA。

打印历史最多保留 20 条、总计 250 MB。原始文件保存在 App 的 Application Support 目录中，不参与设备备份；删除历史记录时，对应文件也会一并删除。

## 已验证环境

当前组合已经过真实打印测试：

- iOS 16.5.1 与 TrollStore；
- 联想 LJ2600D，通过 USB 连接到光猫；
- LPD 地址 `192.168.1.1:515`；
- LPR 队列 `LJ2600D`；
- 单面、自动双面、图片灰度、1/2/4 合 1 打印。

地址和队列都可以在 App 中修改。其他打印服务器可以尝试使用，但打印机本身必须理解当前编码器生成的数据。

## 安装与使用

1. 从 [Releases](https://github.com/Sleepyhead-ui/LJ2600DPrint/releases) 下载最新的 `LJ2600DPrint-TrollStore-*.ipa`。
2. 使用 TrollStore 安装并启动 App。
3. 在打印服务设置中填写光猫或打印服务器地址及 LPR 队列。
4. 选择 PDF 或图片，检查预览并调整打印设置。
5. 确认打印服务在线后发送任务。

当前 GitHub Actions 产物使用 `ldid` 临时签名，适合 TrollStore。个人签名、Ad Hoc、企业签名或其他侧载方式需要使用自己的证书和描述文件重新签名；免费 Apple ID 签名通常只有 7 天有效期。

## 打印服务恢复

App 会在渲染任务前检查 TCP 515 端口。如果服务离线，用户可以在受支持的烽火光猫上填写网关 MAC 地址并尝试恢复。恢复流程使用光猫本地维护接口和由 MAC 派生的 Telnet 凭据，检查 `/dev/lp0`，随后启动已经部署的可撤销守护脚本，或使用临时 LPD 服务作为后备。若 Telnet 是由 App 开启的，流程结束后会自动关闭。

MAC 地址只保存在 App 的本地偏好设置中，不会写入公开仓库，也不会发送到局域网之外。

此恢复机制依赖具体的光猫型号、固件和已经部署的脚本，不能假定适用于其他运营商设备。请只在自己拥有或获准管理的网络设备上使用。

## 诊断报告

“打印服务”页面中的“诊断与支持”可以只读检测 LPR 端口 515 和维护端口 23，并导出文本报告。诊断会记录打印参数、栅格生成耗时、任务大小、LPR 协议阶段和恢复结果，最多保留 250 条和 30 天。

事件在保存和导出时都会脱敏。报告不包含文档名称或内容、完整 IP/MAC、Telnet 凭据和密码；诊断目录也会排除设备备份。端口自检不会发送打印任务、开启 Telnet 或修改光猫设置。

## 兼容性说明

当前编码器是针对 LJ2600D 实机结果逐步校准的。Windows 驱动信息表明该机型与 Brother HL-2240D 系列关系较近，但项目不保证其他联想或兄弟打印机可以直接使用。

更换光猫或路由器后，只要新设备仍能通过 LPR 暴露这台打印机，通常只需修改地址和队列。更换打印机则可能需要适配新的栅格格式、打印语言、纸张参数和双面指令。原生支持 AirPrint、IPP、PCL 或 PostScript 的设备更适合使用其标准打印方式。

## GitHub Actions 构建

将项目推送到 GitHub 后，运行 **Build TrollStore IPA** 工作流。工作流会：

1. 使用 XcodeGen 生成 Xcode 工程；
2. 为 `iphoneos` 构建未使用苹果开发者证书签名的 App；
3. 使用 `ldid` 添加临时签名；
4. 打包并上传 `LJ2600DPrint.ipa`。
